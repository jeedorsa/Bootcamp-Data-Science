## 📋 Información importante

### Actividades CORE
Las actividades CORE son **obligatorias** para el módulo. Para acceder al examen final, deberán completar al menos el **90%** de estas.

### Asistencia a clases
La asistencia a las clases principales con el instructor es **obligatoria**. Asimismo, deberán participar en los talleres prácticos, los cuales forman parte integral del proceso formativo.
En caso de presentar alguna dificultad o compromiso que les impida asistir, les solicitamos informar con anticipación.

### Modalidad de clases
Las clases se realizarán a través de **Zoom**. Les recomendamos descargar e instalar la aplicación con anticipación para evitar inconvenientes al momento de conectarse.

## 📚 Estructura del curso

| Semana | Módulo | Temas |
|--------|--------|-------|
| 1 | DS Fundamentals | Introducción, Google Colab, Input/Output, Lógica y condicionales |
| 2 | DS Fundamentals | Introducción a pandas, Filtrado, Limpieza de datos |
| 3 | DS Fundamentals | Groupby, Apply, EDA |
| 4 | DS Fundamentals | Histogramas, Subplots, Guardar plots, Plotly Express |
| 5 | Machine Learning | Intro ML, Tipos de aprendizaje, Preprocesamiento, Tuberías |
| 6 | Machine Learning | Regresión lineal, KNN, Árboles, Métricas |
| 7 | Machine Learning | Clasificación, KNN, Árboles de decisión |
| 8 | Machine Learning | GridSearch, LazyPredict, XGBoost, LGBM |
